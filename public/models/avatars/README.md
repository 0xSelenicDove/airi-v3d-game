# Sample avatars

The game uses these public VRM 1.0 avatars when `public/model.vrm` or `public/model2.vrm` does not exist. Both come from the official VRM samples in [vrm-c/vrm-specification](https://github.com/vrm-c/vrm-specification/tree/master/samples) and are under the [VRM Public License 1.0](https://vrm.dev/licenses/1.0/).
